## Projetos

### Zephyr API - Plataforma de Inteligência Climática
Aplicação Full Stack que consulta dados climáticos em tempo real e gera alertas de vento e chuva, com resumos em português para o usuário.

- Autenticação com Spring Security e JWT
- Integração com a OpenWeather API
- Mensageria assíncrona com RabbitMQ
- Recomendações geradas com IA generativa
- Documentação com Swagger/OpenAPI e testes com JUnit e Mockito

[Back-end](https://github.com/pamella-binotto/Zephyr-api) · [Front-end](https://github.com/pamella-binotto/zephyr-frontend)

### Stock Control - Sistema de Controle de Estoque
Aplicação Full Stack para gerenciamento de produtos, com API em Java e Spring Boot e interface em React.

- CRUD completo, com busca em tempo real
- Persistência em PostgreSQL com Docker
- Arquitetura em camadas: Controller, Service e Repository
- Validação de dados e tratamento de erros

[Back-end](https://github.com/pamella-binotto/Stock-Control) · [Front-end](https://github.com/pamella-binotto/Stock-Control-Frontend) · [Aplicação publicada](https://stock-control-frontend-kqxm.onrender.com)
